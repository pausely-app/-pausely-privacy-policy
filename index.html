1. Information We Access

Usage Access

Pausely may request access to app usage information on your device through Android's Usage Access permission. This access allows the app to detect which selected apps are being used and for how long.

Pausely may also use a foreground service to monitor app usage in the background and provide timely notifications related to usage limits.

2. How We Use Information

App usage information is used only to provide the core features of Pausely, including:

  • Tracking app usage time;
  • Showing usage statistics to the user;
  • Applying user-defined usage limits;
  • Sending notifications when usage limits are reached;
  • Keeping monitoring active when the user enables background monitoring.

3. Data Storage

Local Storage

Pausely stores app usage and settings data locally on your device. Pausely does not send app usage or settings data to a server in the current version described by this policy.

If future versions of Pausely introduce account features, cloud backup, analytics, or server-side storage, this Privacy Policy will be updated to explain what data is collected, how it is used, and how users can control or delete it.

4. Data Sharing

No Sale of Data

Pausely does not share app usage data with third parties for advertising, marketing, or profiling purposes.

Pausely does not sell personal data.

5. Foreground Service Usage

Foreground Service

Pausely may run a foreground service to monitor app usage while the app is not actively open. This is required for the app's screen-time tracking and limit notification features to work reliably.

The foreground service is used only for active app usage monitoring and notification delivery. Users can stop or disable monitoring from within the app.

6. Permissions Used

Pausely may request the following permissions depending on the Android version and enabled features:

  • Usage Access: Used to read app usage activity so Pausely can calculate screen time and enforce limits.
  • Notifications: Used to notify users when usage limits are reached or monitoring is active.
  • Foreground Service: Used to keep app usage monitoring active in the background.
  • Boot Completed: Used only when the user enables automatic restart of monitoring after device reboot.

7. User Control

Users can control Pausely's monitoring features inside the app. Users can also revoke permissions at any time through Android system settings.

If Usage Access permission is disabled, Pausely may not be able to track app usage or enforce usage limits.

8. Data Retention and Deletion

Locally stored app usage data and app settings remain on the user's device unless the user clears the app data or uninstalls the app.

Users can delete locally stored data by using the app's available controls, clearing app storage from Android settings, or uninstalling the app.

9. Children's Privacy

Pausely is not designed to knowingly collect personal information from children. If you believe that a child has provided personal information through the app, please contact us so we can review the issue.

10. Security

Pausely uses reasonable technical measures to protect locally stored data. However, no method of storage or transmission is completely secure.

11. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated "Last updated" date.
